# 🌐 Static Website Hosting using Amazon S3

This project demonstrates hosting a static website using Amazon S3 without using a traditional web server. The website was configured for public access and served directly through Amazon S3 static website hosting.

## 🚀 Features
- Hosted a static HTML/CSS website using Amazon S3
- Configured static website hosting on an S3 bucket
- Uploaded website files (HTML/CSS assets) to S3
- Configured bucket policy and public access permissions
- Accessed website through S3 static website endpoint

## 🛠️ Technologies Used
- Amazon S3
- HTML/CSS
- AWS Management Console

## ☁️ Deployment Architecture
- Created an S3 bucket to host website files
- Uploaded static website assets to the bucket
- Enabled static website hosting in bucket properties
- Configured bucket permissions for public access
- Accessed website using generated S3 endpoint URL

## 📊 AWS Evidence
- S3 bucket created and configured for website hosting
- Static website hosting enabled successfully
- Public bucket policy configured for browser access
- Website verified using S3 endpoint URL
