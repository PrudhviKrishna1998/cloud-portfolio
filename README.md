# ☁️ AWS Cloud Portfolio

This repository contains hands-on cloud computing projects built using Amazon Web Services (AWS), covering core cloud concepts such as compute, networking, storage, monitoring, scaling, and database services.

The goal of this portfolio is to demonstrate practical AWS experience through real-world implementations and troubleshooting.

---

## 🚀 Project 1: AWS EC2 Networking & Database Project
Built a cloud infrastructure environment using EC2, IAM, VPC networking, and Amazon RDS.

### Key Highlights
- Hosted portfolio website using EC2 and nginx
- Configured IAM users, permissions, and IAM roles
- Implemented secure SSH access using key pairs
- Designed public/private subnet architecture
- Accessed private EC2 securely through bastion host
- Configured Security Groups for controlled access
- Connected EC2 to Amazon RDS MySQL database
- Performed SQL operations and secure connectivity testing

📁 Folder: `ec2-networking-rds/`

---

## 🌐 Project 2: Static Website Hosting using Amazon S3
Hosted a static website using Amazon S3 without a traditional web server.

### Key Highlights
- Hosted static HTML/CSS website on S3
- Enabled static website hosting
- Configured bucket policies and public access
- Accessed website through S3 static endpoint

📁 Folder: `s3-static-website/`

---

## 📈 Project 3: AWS Monitoring, Load Balancing & Auto Scaling
Implemented monitoring, high availability, and automatic scaling using AWS services.

### Key Highlights
- Monitored EC2 metrics using Amazon CloudWatch
- Created CPU alarms with SNS email notifications
- Configured Application Load Balancer (ALB)
- Distributed traffic across multiple EC2 instances
- Implemented Auto Scaling Group for dynamic scaling
- Tested automatic EC2 scaling under load

📁 Folder: `aws-monitoring-scaling/`
